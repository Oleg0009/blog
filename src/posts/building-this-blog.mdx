# Building This Blog

This blog started because at some point I realized my progress in certain skills had
stalled, and I needed to improve myself and push some updates into both my life and my
technical skills. First and foremost it's for my own growth — I don't want to stay where
I am; I want to keep moving forward through this whole AI boom, knowing I still have real
gaps: skills that are simply missing and things I use without even knowing how they work.
This is where I start closing them.
